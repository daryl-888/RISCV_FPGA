# RISC-V FPGA — historical repository

This repository is preserved as historical material. The active eight-week SystemVerilog course is in:

- [RISCV_FPGA_Practice](https://github.com/daryl-888/RISCV_FPGA_Practice) — learner interfaces, weekly labs, public tests and textbook assignments.
- [RISCV_FPGA_Teacher](https://github.com/daryl-888/RISCV_FPGA_Teacher) — private instructor reference and lesson preparation.

The course ends with a five-stage IF/ID/EX/MEM/WB pipeline, including forwarding, load stalls, control flushing and MMIO verification. The single-cycle core is an intermediate milestone.

Both active repositories are private at this revision; links require permission. Ask the owner for Practice access. This landing page does not publish the instructor answer key or grant repository access.

Existing files below are historical snapshots, not the maintained course or current setup instructions. No source/history has been deleted. Repository archival is a separate owner-settings operation after the redirect is published.
